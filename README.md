CSC 111 - library Simulator (Phase 2)

this rspository contains the Phase 2 implementation of the library simultion project for csc111 KSU course 

Description:
The project simulates a simple library system where users can:
- View the number of borrowed books  
- Borrow a book (with a fee of 0.50)  
- Return a book  
- View session statistics  


An **Administrator** can:
- View total revenue generated  
- Check the most frequent operation (borrow or return)
